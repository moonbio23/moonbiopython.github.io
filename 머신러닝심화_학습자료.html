클러스터링 (Clustering)
💡

핵심 개념: 클러스터링은 정답 레이블 없이 데이터를 비슷한 그룹으로 묶는 비지도 학습입니다. Wine 데이터(13개 피처)를 PCA → 2D 시각화하고 3가지 알고리즘으로 군집화합니다.

📘 Notebook 01

Mean Shift

데이터 밀도가 높은 방향으로 중심점을 이동시켜 자연스러운 클러스터를 찾습니다. 클러스터 개수를 미리 지정하지 않아도 됩니다.

발견 클러스터 3개  ✅ 실제 클래스 수(3)와 일치
📙 Notebook 02

DBSCAN

밀도가 충분한 지역을 클러스터로, 고립된 점을 노이즈(−1)로 분류합니다. 이상치 자동 탐지에 강합니다.

클러스터 3개  노이즈 23개
📗 Notebook 03

GMM

데이터가 여러 가우시안 분포의 혼합이라고 가정합니다. 각 데이터가 각 클러스터에 속할 확률(predict_proba)을 반환합니다.

AIC/BIC 최소 n=3  소프트 클러스터링

Mean Shift 핵심 코드

Python · notebook 01
from sklearn.cluster import estimate_bandwidth, MeanShift from sklearn.preprocessing import StandardScaler from sklearn.decomposition import PCA # ① 표준화 — Mean Shift는 거리 기반이므로 단위 통일이 필수 X_scaled = StandardScaler().fit_transform(X) # ② PCA 2D 축소 — 13차원을 눈으로 보기 위한 시각화 용도 X_pca = PCA(n_components=2).fit_transform(X_scaled) # ③ 최적 대역폭 자동 추정 (quantile=0.2 → 전체의 20% 거리 사용) bandwidth = estimate_bandwidth(X_scaled, quantile=0.2) # ④ 학습 (bin_seeding=True → 격자 기반 시작점으로 속도 향상) ms = MeanShift(bandwidth=bandwidth, bin_seeding=True) ms.fit(X_scaled) # ⑤ 결과 확인 n_clusters = len(set(ms.labels_)) # → 3

DBSCAN 핵심 코드

Python · notebook 02
from sklearn.neighbors import NearestNeighbors from sklearn.cluster import DBSCAN # ① K-Distance Plot으로 eps 추정 # → 5번째 이웃까지 거리를 내림차순 정렬 → 꺾이는 지점 = 최적 eps nbrs = NearestNeighbors(n_neighbors=5).fit(X_scaled) distances, _ = nbrs.kneighbors(X_scaled) k_dist = np.sort(distances[:, -1])[::-1] # ② DBSCAN 적용 dbscan = DBSCAN(eps=0.55, min_samples=5) dbscan.fit(X_scaled) # 레이블 -1 = 노이즈 포인트 n_noise = sum(dbscan.labels_ == -1) # → 23

GMM 소프트 클러스터링

from sklearn.mixture import GaussianMixture gmm = GaussianMixture(n_components=3, random_state=42) gmm.fit(X_scaled) # 소프트 클러스터링 — 각 클러스터에 속할 확률 proba = gmm.predict_proba(X_scaled) # 예: [0.00, 0.00, 1.00] → 클러스터 2에 100% 확실 # [0.95, 0.05, 0.00] → 클러스터 0에 95% (경계 지점) # AIC/BIC로 최적 클러스터 수 탐색 aic_scores = [GaussianMixture(n_components=n, random_state=42).fit(X_scaled).aic(X_scaled) for n in range(1, 8)] # → 최소값 n=3

📘 Notebook 04 · 회귀

LassoCV + Pipeline

L1 규제로 불필요한 피처 계수를 0으로 만들어 자동 선택합니다. Pipeline으로 스케일링-선택-모델을 한 번에 처리해 데이터 누수를 방지합니다.

선택 피처 + Ridge → R² 향상
📘 Notebook 05 · 분류

RFECV (Random Forest)

1개씩 피처를 제거하며 교차검증 성능이 최대인 개수를 찾습니다. StratifiedKFold로 클래스 불균형을 유지합니다.

8개 → 6개  Acc: 0.7597 → 0.7727
📘 Notebook 06 · SVC

SVC (Linear + RBF)

피처 선택은 Linear SVC(coef_ 필요), 최종 예측은 RBF SVC로 분리합니다. StandardScaler 필수.

3피처 선택  Acc: 0.7208 (+0.0195)
📘 Notebook 07 · SVR

SVR (epsilon-tube)

회귀용 SVM. ε 범위 안의 오차는 무시합니다. 5개 피처 선택 후 RMSE 개선.

5피처 → RMSE: 49.56 R²: 0.5365

SVM 핵심 코드 — Pipeline으로 데이터 누수 방지

Python · notebook 06
from sklearn.pipeline import Pipeline from sklearn.svm import SVC from sklearn.feature_selection import RFECV from sklearn.model_selection import StratifiedKFold # Pipeline = 스케일링 → 피처선택 → 예측을 한 묶음으로 # X_test에 fit이 아닌 transform만 적용 → 데이터 누수 자동 방지 pipe_svc = Pipeline([ ('scaler', StandardScaler()), ('selector', RFECV( estimator=SVC(kernel='linear'), # coef_ 있어야 RFECV 사용 가능 step=1, cv=StratifiedKFold(5), scoring='accuracy' )), ('clf', SVC(kernel='rbf', random_state=42)) # 비선형 예측 ]) pipe_svc.fit(X_train, y_train) # 결과: 8개 → 3개 선택 (preg, plas, mass) # Accuracy: 0.7013 → 0.7208
🔑

왜 두 가지 커널? Linear SVC는 coef_ 속성이 있어 RFECV가 피처 중요도를 계산할 수 있습니다. RBF SVC는 비선형 패턴 학습에 강해 최종 예측 성능이 더 높습니다.

from sklearn.ensemble import RandomForestClassifier from sklearn.model_selection import GridSearchCV, StratifiedKFold rf = RandomForestClassifier(random_state=42) # 트리 기반 → StandardScaler 불필요 param_grid = { 'n_estimators': [100, 200, 300], 'max_depth': [None, 5, 10, 20], 'min_samples_leaf':[1, 2, 4], 'max_features': ['sqrt'] } # 3×4×3×1 = 36 조합 × 5 fold = 180번 학습 grid = GridSearchCV(rf, param_grid, cv=StratifiedKFold(5), scoring='accuracy') grid.fit(X_train, y_train) # 피처 중요도 — 1위: plas(혈당) = 0.298 importances = grid.best_estimator_.feature_importances_ # 상위 5개 피처만으로 재학습 → 오히려 성능 향상! top5_features = X.columns[np.argsort(importances)[-5:]] # Accuracy: 0.7403 → 0.7792 (나머지 3개가 노이즈였음)

부스팅 핵심: 이전 모델이 틀린 부분에 집중하며 순차적으로 학습합니다. 약한 학습기(weak learner)를 여러 개 결합해 강한 모델을 만듭니다. 배깅은 병렬, 부스팅은 순차!

📅 부스팅 알고리즘 진화 타임라인

2001

2014
XGBoost

2017
LightGBM 🏆
Leaf-wise 성장 + 히스토그램 기반. XGBoost보다 빠르고 메모리 효율적. 분류 최고 성능(0.7857).
2017
CatBoost 🏆

XGBoost vs LightGBM 트리 성장 방식

XGBoost — Level-wise 성장

모든 레벨을 균일하게 확장합니다. 안정적이지만 느립니다. 필요 없는 노드도 분할됩니다.

LightGBM — Leaf-wise 성장 ⚡

손실이 가장 큰 리프 하나만 분할합니다. 더 빠르고 더 작은 오차를 달성합니다. num_leaves로 복잡도 제어.

XGBoost 주요 파라미터

n_estimators
트리 개수. Early Stopping과 함께 사용하면 자동 최적화.
탐색 범위: 100 ~ 500
learning_rate
각 트리의 기여도. 낮을수록 안정적이지만 트리가 더 많이 필요.
로그 스케일: 0.001 ~ 0.3
max_depth
트리 최대 깊이. 낮을수록 과적합 감소.
탐색 범위: 3 ~ 10
subsample
각 트리에서 사용할 데이터 비율. 0.8 = 80%만 사용.
탐색 범위: 0.6 ~ 1.0
colsample_bytree
각 트리에서 사용할 피처 비율. RF의 무작위 피처 선택과 유사.
탐색 범위: 0.6 ~ 1.0
reg_alpha / lambda
L1(alpha)/L2(lambda) 규제. 과적합 방지에 효과적.
reg_alpha: 0~1, lambda: 0~2

스태킹 핵심 코드

Python · notebook 20
from sklearn.ensemble import StackingClassifier, RandomForestClassifier, GradientBoostingClassifier from sklearn.linear_model import LogisticRegression base_models = [ ('rf', RandomForestClassifier(n_estimators=100, random_state=42)), ('gb', GradientBoostingClassifier(n_estimators=100, random_state=42)), ('xgb', XGBClassifier(n_estimators=100, random_state=42)), ('lgbm', LGBMClassifier(n_estimators=100, random_state=42, verbose=-1)), ('svc', SVC(kernel='rbf', probability=True)) # probability=True 필수! ] stacking = StackingClassifier( estimators=base_models, final_estimator=LogisticRegression(), cv=5 # OOF 예측을 위한 5-fold 교차검증 ) # 메타 모델 C 파라미터 최적화 grid_stack = GridSearchCV(stacking, {'final_estimator__C': [0.1, 1.0, 10.0]}, cv=5) grid_stack.fit(X_train_scaled, y_train) # 최적 C=10.0, Test Accuracy=0.7597
📌

스태킹이 항상 최고가 아닙니다! 이 데이터에서는 LightGBM 단독(0.7857) > Stacking(0.7597). 스태킹은 분산을 줄이는 효과가 있어 불안정한 데이터나 여러 약한 모델을 결합할 때 더 유리합니다.

import optuna def objective_xgb(trial): params = { 'n_estimators': trial.suggest_int('n_estimators', 100, 500), 'learning_rate': trial.suggest_float('learning_rate', 1e-3, 0.3, log=True), # 로그 스케일 'max_depth': trial.suggest_int('max_depth', 3, 10), 'subsample': trial.suggest_float('subsample', 0.6, 1.0), 'colsample_bytree':trial.suggest_float('colsample_bytree', 0.6, 1.0) } model = XGBClassifier(**params, random_state=42) return cross_val_score(model, X_train, y_train, cv=5).mean() # 최적화 실행 (TPE sampler가 이전 결과를 기반으로 다음 탐색 지점 결정) study = optuna.create_study(direction='maximize') study.optimize(objective_xgb, n_trials=50) print(study.best_params) print(study.best_value) # XGBoost CV: 0.7769 # 파라미터 중요도 시각화 optuna.visualization.plot_param_importances(study)

from scipy.stats import loguniform, randint, uniform, expon param_distributions = { 'learning_rate': loguniform(1e-3, 1e-1), # 로그 균등: 작은 값에 더 집중 'n_estimators': randint(100, 1001), # 정수 균등: 100~1000 'subsample': uniform(0.6, 0.4), # 실수 균등: 0.6~1.0 'gamma': expon(scale=2) # 지수 분포: 주로 작은 값 } # loguniform(1e-3, 1e-1): 0.001~0.1 범위에서 0.001~0.01 vs 0.01~0.1 동일 확률 # → learning_rate처럼 작은 값이 중요한 파라미터에 적합

XAI — SHAP 분석
💎

SHAP 핵심: 게임 이론(Shapley Value)을 머신러닝에 적용. "이 환자의 당뇨 예측에 혈당이 +0.3, 나이가 +0.1, BMI가 −0.05 기여했다"는 식으로 블랙박스 모델을 설명합니다.

SHAP 시각화 종류 & 용도

시각화확인 가능한 것언제 사용
Summary Plot (Beeswarm)전체 피처의 영향 분포전반적 패턴 파악 — 가장 먼저
Bar Plot평균 절댓값 피처 중요도 순위중요 피처 목록 확인
Force Plot개별 샘플 1개의 예측 설명특정 환자 설명
Waterfall Plot단계별 예측값 형성 과정개별 예측 추적
Dependence Plot피처 값 vs SHAP 값 (상호작용)비선형 관계 파악
Decision Plot여러 샘플의 예측 경로 비교그룹별 패턴 비교

import shap # ① TreeExplainer 생성 — 트리 기반 모델 전용, 빠르고 정확 explainer_lgbm = shap.TreeExplainer(best_lgbm) # ② SHAP 값 계산 shap_values_lgbm = explainer_lgbm.shap_values(X_test) # ⚠️ LightGBM 이진 분류: [음성 클래스, 양성 클래스] 반환 # → 당뇨 양성(1) 예측을 보려면 인덱스 1 사용! shap_vals = shap_values_lgbm[1] # ③ Summary Plot — 전체 패턴 확인 shap.summary_plot(shap_vals, X_test) # 색상: 빨강=높은 피처값, 파랑=낮은 피처값 # x축: 양수=예측 증가, 음수=예측 감소 # ④ Force Plot — 개별 샘플 1개 설명 shap.force_plot( explainer_lgbm.expected_value[1], shap_vals[0], # 첫 번째 테스트 샘플 X_test.iloc[0] ) # ⑤ Dependence Plot — plas(혈당)과 mass(BMI) 상호작용 shap.dependence_plot( 'plas', shap_vals, X_test, interaction_index='mass' ) # → "혈당이 높을수록 당뇨 예측 ↑, BMI가 높을 때 그 효과가 더 강함"
